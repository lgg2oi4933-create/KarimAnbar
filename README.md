# حسابداری تولیدی سینی — مرحله ۷

وب‌اپ نصب‌شدنی (PWA) برای اندروید. اطلاعات فقط روی خود گوشی ذخیره میشود.

## چه چیزهایی در این مرحله هست
- ورود با رمز برای هر کاربر (چند مدیر ممکن است)، کد بازیابی، قفل خودکار
- فاکتور خرید و فروش (مالیات قابل ویرایش، خروجی تصویر و PDF)
- دریافت و پرداخت نقدی، چک و حواله؛ چک‌ها با وضعیت (در جریان، وصول، برگشتی، خرج‌شده) و یادآوری سررسید
- حساب هر شخص (بدهکار/بستانکار)، صورت‌حساب با فیلتر تاریخ و خروجی
- افزودن دسته‌بندی کالا هنگام ساخت کالا
- خرج چک با انتخاب فاکتور؛ لیست بدهکاران/بستانکاران از صفحه‌ی خانه
- جمع نقد/چک/حواله‌ی دریافتی و پرداختی در صفحه‌ی دریافت و پرداخت
- گزارش‌ها (بیشتر ← گزارش‌ها): فروش/خرید/دریافتی/پرداختی ماه، سود هر محصول، هر مشتری و هر ماه (از «قیمت تمام‌شده»ی واردشده در فاکتور فروش)، کم‌موجودی و ویجت‌های صفحه‌ی خانه
- بک‌آپ و ادغام (بیشتر ← بک‌آپ و ادغام، فقط مدیر): فایل کامل یا بخشی برای تلگرام، ادغام فایل گوشی دیگر (ویرایش جدیدتر می‌ماند)، یادآوری بک‌آپ هفتگی
- انبار: موجودی فقط از فاکتورهای خرید/فروش و ورود/خروج دستی (علت‌ها: مصرف در تولید، تولید شده، ورود ضایعات برش، ...) برای همه‌ی کالاها، کاردکس، و «شماره تولید» اختیاری با گزارش جمع ورود/خروج هر شماره
- فاکتور فروش: فیلد «قیمت تمام‌شده» هر ردیف (فقط داخل برنامه، در تصویر/PDF نمی‌آید) و بخش «سود این فاکتور»؛ فاکتور خرید خدمات (مثلاً اجرت برون‌سپار) روی موجودی اثر ندارد
- نیروی انسانی (بیشتر ← نیروی انسانی، فقط مدیر): نیروها، حضور و غیاب، مرخصی روزانه/ساعتی، دستمزد عادی و اضافه‌کاری، حقوق و پرداخت با بازه، گزارش
- ثبت با صدا (فقط با اینترنت/VPN و کلید Gemini روی همان گوشی): فاکتور فروش/خرید، دریافت/پرداخت و ورود/خروج انبار؛ بعد از تشخیص، فرم پر میشود و قبل از ذخیره قابل ویرایش است. کلید در بک‌آپ نمی‌آید.
- اشخاص (مشتری / تأمین‌کننده / برون‌سپار؛ یک نفر میتواند چند نقش داشته باشد)
- کالاها (ورق، چسب، نوار چسب، سینی، ضایعات، خدمات، سایر) با دسته‌بندی درختی
- تقویم شمسی، ارقام فارسی، کد خودکار قابل ویرایش
- کاربران (مدیر / حسابدار) و گزارش فعالیت
- اطلاعات و لوگوی شرکت، پوسته‌ی روشن/تیره
- کار آفلاین بعد از اولین باز شدن

## قراردادن روی GitHub Pages
۱. در github.com یک مخزن (Repository) **Public** بسازید، مثلاً `tray-app`.
۲. همه‌ی فایل‌های این پوشه (نه خود پوشه) را با Add file ← Upload files آپلود کنید و Commit بزنید.
۳. Settings ← Pages ← Source: «Deploy from a branch»، Branch: `main` و پوشه‌ی `/ (root)` ← Save.
۴. بعد از ۱ تا ۲ دقیقه آدرس `https://نام‌کاربری.github.io/tray-app/` ساخته میشود.
۵. آن را در Chrome گوشی باز کنید ← منو (سه نقطه) ← «Install app» / «افزودن به صفحه‌ی اصلی».

## بعد از هر تغییر در کد
`node tools/make-precache.mjs` را اجرا کنید تا گوشی نسخه‌ی جدید را بشناسد.

## ساختار (ماژولار)
- `js/core/` هسته: ذخیره‌سازی، مخزن داده، تقویم شمسی، مسیریاب، ثبت ماژول
- `js/ui/` اجزای مشترک رابط
- `js/modules/*` هر ماژول مستقل؛ ثبتشان فقط در `js/app.js`
- `tests/` تست‌های خودکار (`npm test`)
